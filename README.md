## Module Slider ##

Module Slider is a minimal mod that allows you to, through ModuleManager configs, add a slider to a part and control a value on that part with said slider per-part in-game.  An example config is included, along with a config for some Stockalike Station Parts Redux centrifuges (which is the main reason I made this).

Why use this instead of config editing?  If you want to permanently edit the stats for a part, you shouldn't.  However if you want to be able to fine-tune certain values per part(like the spin rate for a centrifuge, for exapmle) this mod allows you to do that, and it also lets you rapidly prototype your changes in-game.
More intended for custom config makers who might appreciate something like this to provide either more control or faster testing of custom values.
